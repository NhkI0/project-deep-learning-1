# MLP/DNN Comparative Study Project

## 📖 Project Overview

This project is a comparative study of Multi-Layer Perceptrons (MLP) and Deep Neural Networks (DNN) applied to structured data. The objective is to solve both **classification** and **multi-output regression** problems within a specific applicative scenario.

We implement these solutions using three major machine learning frameworks: **Scikit-learn**, **TensorFlow**, and **PyTorch**, ensuring high code quality and strict adherence to PEP-8 standards.
